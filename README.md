## Publishing

This repository is the authoritative source for the book website. GitHub Pages publishes the root directory of the main branch automatically after commits. Edit index.html and the assets or campaign folders here, then commit to main and verify the Pages deployment succeeds.

The site does not require ChatGPT Sites or a separate ChatGPT publishing step. The DNS CNAME for books.familygallerytv.com points to arianaanderson.github.io. The domain remains registered at Porkbun.

The initial migration copied all 71 book-site files unchanged from ArianaAnderson/the-family-gallery at commit 6d7eb869a1bb4e348b1f02c8d051f57b59397d0c. The original repository retains the earlier version history. That repository continues hosting the Family Gallery TV art website separately.

Keep CNAME and .nojekyll in the repository. Do not change the root art website, domain nameservers, or email records when editing this book site.
